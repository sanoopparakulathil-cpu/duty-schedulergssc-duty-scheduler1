# GSSC Daily Duty & Site Operations Scheduler

A responsive, single-file web application built for Gulf Safety & Security Co. Ltd. (GSSC) to manage daily technician duty scheduling, daytime site work orders, urgent site prioritization, and one-click WhatsApp duty roster broadcasts.

## Features
- **Daytime Site Intake**: Add new sites on the fly with client, location, system type, time window, and scope.
- **Color-Coded Technicians**: 14 distinct badge colors for instant technician identification.
- **Urgent Priority Alerts**: 1-day advance red border/badge alerts for critical repair jobs.
- **Roster Accountability**: Mandatory absence reason logging for unassigned technicians.
- **Daily Ordered Sites List**: Isolated view of all sites scheduled for the day with print & export tools.
- **1-Click WhatsApp Copy**: Pre-formatted markdown broadcast ready to paste into team WhatsApp group with supervisor auto-sign (`Sanoop Parakulathil Antony - 8526`).

## Deploying to GitHub Pages
1. Upload `index.html` and `README.md` to a new GitHub repository.
2. Go to **Settings** > **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch** > branch: `main` > folder: `/ (root)`.
4. Click **Save**. Your application will be live at `https://<your-username>.github.io/<repo-name>/`.
